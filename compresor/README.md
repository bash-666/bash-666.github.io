# Compresor de Audio

Página web para comprimir audios por lotes, directamente en el navegador.

- Entrada y salida: mp3, ogg, opus y wav
- Cola por lotes con progreso por archivo
- Conserva el nombre original de cada archivo (solo cambia la extensión)
- Descarga individual, todo en un zip, o guardar en una carpeta elegida
- Sin servidor: los archivos nunca salen del dispositivo

Usa ffmpeg.wasm (WebAssembly), así que no hace falta instalar nada.

Dirección: https://bash-666.github.io/compresor/
